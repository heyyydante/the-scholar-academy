# The Scholar Academy — Multi-page website

This is the consolidated project package. It includes the homepage and all linked internal pages, with the supplied school logo and brochure-based content.

## Pages
- `index.html` — Home
- `about.html` — About the school and mission
- `academics.html` — Nursery, LKG, UKG and Classes I–V
- `facilities.html` — Facilities listed in the brochure
- `activities.html` — Art & craft, sports, activity-based learning and values
- `gallery.html` — Ready-made photo placeholders for future school photographs
- `admissions.html` — Admission information and tap-to-call numbers
- `contact.html` — Address and phone contact details

## Shared files
- `style.css` — all site styling and mobile breakpoints
- `script.js` — mobile menu, scroll reveal and current copyright year
- `assets/scholar-academy-logo.jpg` — supplied school logo

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` using Live Server.
4. Use the navigation to open each separate page.

## Photo placeholders
No school photographs were provided, so this version uses designed visual placeholders rather than unrelated stock photos. When photos are available, place approved images in `assets/` and replace the placeholder blocks in `index.html` or `gallery.html`.
